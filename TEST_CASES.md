# DriveSense test checklist

| ID | Action | Expected result |
|---|---|---|
| TC-01 | Launch DriveSense | Dashboard shows Start Monitor and View History. |
| TC-02 | Open Live Drive Monitor | Timer, score, graph, sensitivity sliders, and controls are visible. |
| TC-03 | Tap Run Safe Demo Events | Three sample events appear; the timer and score update. |
| TC-04 | Tap Finish & Save Drive | A session is saved and the History screen opens. |
| TC-05 | Review History | The session lists date, duration, score, and individual event details. |
| TC-06 | Close/reopen, then open History | Saved sessions remain available. |
| TC-07 | Enable Driving mode on a real phone | Live linear acceleration and gyroscope values update. |
| TC-08 | Move the sensitivity sliders | Lower thresholds detect smaller movements; higher thresholds reduce detections. |
| TC-09 | Check App info > Permissions | No location, camera, microphone, or internet permission is requested. |
| TC-10 | Tap a saved session in History | Drive Details opens with a score label, coaching tip, and event-by-event review. |
| TC-11 | Return to Dashboard after saving drives | The dashboard summary shows saved-drive count, average score, and latest result. |
